# Todo List

Aplikasi Todo List sederhana dengan HTML, CSS, dan JavaScript.

## Fitur

- Menambahkan task
- Mengedit task
- Menghapus task
- Menandai task selesai
- Data tersimpan di LocalStorage

## Cara menjalankan

1. Clone repo ini
   `git clone https://github.com/rizkilabs/todo-list.git`
2. Buka file `index.html` di browser

## Demo

https://rizkilabs.github.io/todo-list

## Teknologi

HTML, CSS, JavaScript (vanilla)
